[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## Overview
Zende is a web based travel journal, which helps in keeping memories about places you visited, how long you stayed and what mood you were in while visiting there.

## Features
- CRUD: Create, Read, Update and Delete travel your entries. 
- Map integration: Ability to pin the exact location for 
- Premium Features: Uprade to premium to access features like more travel entries, more image in a travel entry

## Tech Stack
- **Language**: JavaScript ES6
- **Framework**: Vue JS
- **Database**: Supabase(PostgreSQL)
- **Tools**: Git, axios,

## Installation

### Prerequisites
- List required software and versions
- Example: Node.js v14+, npm v6+

### Steps
```bash
# Clone the repository
git clone https://github.com/Nelsonnxx4/my-voyage.git

# Navigate to project directory
cd my-voyage

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
```

## Usage
```bash
# start the dev
npm run dev

# build the dev
npm run build
```
